# YT Business Studio

Landing page for a YouTube business strategy service. It presents the strategic method, monetization models, service offers, a quick diagnostic form, and a WhatsApp contact CTA for consultancies and advisory sessions.

## Quick path

1. Open `index.html` in a browser.
2. Review the landing page sections and responsive layout.
3. Replace the WhatsApp placeholder number before publishing.

## Local preview

You can open the site directly because it is a static HTML page:

```powershell
start index.html
```

Or use a local static server / Live Server extension if you want browser auto-refresh while editing.

## What is included

| Area | Details |
|------|---------|
| Main page | Single-file static landing page in `index.html` |
| Ticker | Continuous horizontal ticker without a visible gap |
| YouTube channels | Own-channel episodes and client podcast work showcased as proof of strategy |
| Lead capture | Quick diagnostic form with an in-page recommendation |
| WhatsApp CTA | Dedicated section for consultancies and advisory conversations |
| Responsive layout | Mobile-friendly grid changes through CSS media queries |

## Before publishing

- [ ] Replace `https://wa.me/000000000000` with the real WhatsApp number in international format.
- [ ] Confirm all CTA links point to the intended sections.
- [ ] Test desktop and mobile viewport sizes.
- [ ] Update the footer name if `nombre de trabajo` should be replaced.

## WhatsApp number format

Use the international number without `+`, spaces, or hyphens.

Example:

```html
https://wa.me/573001234567
```
